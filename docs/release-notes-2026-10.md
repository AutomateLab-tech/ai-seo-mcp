# AI-SEO MCP maintenance update

Repair nine MCP output contracts and report the package version consistently.

Installation, compatibility, reproducible inputs and result limits are documented in [the maintenance guide](maintenance-guide.md). Snapshot products retain source and review dates separately from publication.

The MCP now advertises the fields its handlers actually return in nine affected output schemas. Valid inline Article and FAQ fixtures, malformed JSON, offline llms.txt validation, entity extraction and both rewrite paths pass the MCP client contract. The robots parser now receives an absolute URL so Googlebot and PerplexityBot disallow rules are detected. Training preferences are kept separate from search penalties.
